# CloudHexer Desktop

CloudHexer Desktop for Windows, macOS and Linux: the bridge between your PS5 and your private cloud drive.

**Get the app from the website: [cloudhexer.com/downloads](https://cloudhexer.com/downloads)**

This repository holds only the app's installers, one release per system and version
(for example `windows-v1.5.28`). It contains no source code. The website's download
buttons link to the current installer here.

Each release lists its installer's SHA-256, so you can check the file you downloaded.
The app updates itself from inside the app; you don't need to come back here.

Help and support: [cloudhexer.com](https://cloudhexer.com)
